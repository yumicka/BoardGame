# BoardGame
Galda spēle “Cirkus” tagad ir pieejama digitālajā formātā ! Spēle ir piemērota gan vienam spēlētājam (sākot no diviem spēlētājiem), gan spēlēšanai ar draugiem (no diviem līdz septiņiem spēlētājiem). Spēles noteikumi ir vienkārši: izvēlēties savu tēlu, izvēlēties sev vārdu, un pēc tam, metot spēles kauliņu vairākas reizes, veikt gājienu no vienas līdz sešām šūnām. Pirmais, kurš sasniedz finišu, ir uzvarētājs, taču ne viss ir tik vienkārši — ceļā uz finišu jūs sastapsiet bīstamas šūnas, kas var atgriezt jūs atpakaļ uz starta. Lai uzvarētu šajā spēlē, jums jābūt īstam laimīgajam!

**Darāmo darbu saraksts:**
- [x] Vairāki kursori
- [x] Galvenās izvēlnes animācijas
- [x] Galvenās izvēlnes pogas (sākt, iziet, iestatījumi)
- [x] Rakstzīmju izvēles ekrāns ar animācijām
- [x] Iestatījumu aina
- [x] Galda aina ar metamajiem kauliņiem
- [x] Spēles loģika ar vairākiem spēlētājiem
- [x] Spēles kamera
